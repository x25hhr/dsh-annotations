在对话里拖选文字，按「重要 / 疑问 / 否定 / 补充」做注释。标注过的段落会在对话里保留同色色块，注释面板里的摘录点一下就能跳回原文；最后可以把所有注释汇总插入输入框，继续和 Agent 逐条讨论。

## 用法

1. 用鼠标拖选一段文字（Agent 回答或你自己的消息都可以）。选区旁会出现一条工具栏：`重要`、`疑问`、`否定`、`补充`、`引用`。
2. 点任一分类，这段文字就进入当前会话的注释列表，并在对话里留下该分类的颜色块；点 `引用` 仍按原有方式把选区作为 Markdown 引用插入输入框（不保存注释）。
3. 注释收在输入框下方的「注释 N」里；第一次用之前，这里会显示一行提示。点它展开面板：
   - 点摘录文字：滚动回那段原文并闪烁提示；
   - 分类胶囊可下拉改类别，色块随之换色；
   - 可以单条插入、删除（7 秒内可撤销）、复制清单或清空。
4. 点 `插入全部`，所有注释按顺序拼成一段带分类标签的文本插入输入框：

   ```
   我标注了以下 2 处，想和你逐条讨论：

   1. 【重要】「……」
   2. 【疑问】「……」
   ```

   插入后光标回到输入框，接着写你自己的问题发送即可。

## 说明

- 色块用浏览器原生的 CSS Custom Highlight 绘制，不修改对话的 DOM；消息重新渲染或流式输出时会自动重新定位。
- 为控制开销，单次会话文本量极大（约 40 万字符以上）时会暂停绘制色块，注释与插入功能不受影响。
- 注释按会话分开保存，只存在本机浏览器里，不会自动发给 Agent；只有插入输入框并发送时，Agent 才会看到这些文字。
- 跳回原文时，如果那段内容还在更早的、尚未加载的历史里，会提示先向上滚动加载。
- 工具栏替换了原本「引用」浮动按钮所在的单元，因此「引用」动作保留在工具栏末尾，行为与之前一致。
- 分类、提示语与汇总格式支持中文和英文。
